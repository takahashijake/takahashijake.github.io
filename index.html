UNDER THE HOOD

The engineering behind the work.

01 / LLM-TOWN

Language models don't own the world state.

Problem. LLM-driven simulations can become inconsistent when generated dialogue is treated as ground truth.

Architecture. Speaker-private prompt contexts feed a local model. Parsing, semantic validation, effect-eligibility checks, and deterministic systems separately decide whether any state transition occurs. State includes goals, commitments, economy, materials, evidence, and justice.

Evidence. Deterministic unit/integration tests, dedicated evaluation scripts, persisted records, and frozen version reports are included in the repository. These are inspectable engineering checks, not claims of real-world social validity.

Explore documentation ↗
02 / BENCHFORGE

Compare models without leaking the answer.

Problem. Model selection is unreliable when preprocessing leaks test information, search budgets differ, or experiments cannot be reconstructed.

Architecture. Declarative configurations drive train-only preprocessing, shared cross-validation folds, nested model-family searches, a bounded AutoML planner, and robustness comparisons across repeated matched folds.

Evidence. Versioned artifacts preserve split plans, predictions, metrics, failures, and paired comparisons. The project explicitly scopes bootstrap intervals to observed fold/estimator variation rather than overstating statistical significance.

03 / AGENTBENCH

Make agent evaluations auditable.

Problem. An agent benchmark means little if the task changes between runs or trial artifacts can be corrupted or misattributed.

Architecture. Suite manifests and locks pin task repositories; trials execute in isolated worktrees. Worker leases, fenced completion, campaigns, and digest-checked result bundles support repeatable reporting. The merged Codex adapter parses JSONL events for turn completion, deduplicated tool activity, and termination reasons.

Verified on main · October 8, 2026. CI passes quality, Python 3.11/3.13 integration, and container checks at 9d3280c. Adapter regression tests exercise structured events, malformed output, and timeout handling; these fixture tests do not establish real-agent benchmark performance.

Open QA. Issue #35 identifies raw worker-identity leakage in portable reports; its fix in PR #37 is still unmerged. Campaign progress reporting in PR #40 is also open. Digest verification does not establish privacy safety.

04 / MINIGAME

One engine, two interfaces.

Problem. Maintaining separate gameplay logic for native and browser clients invites subtle divergence.

Architecture. A shared C++17 GameEngine handles state and rules. Terminal adapters and Emscripten bindings expose the same implementation to their respective interfaces.

Verified on main · October 8, 2026. CI passes native builds and CTest on Linux, macOS, and Windows, Linux sanitizer tests, JavaScript syntax validation, and a WebAssembly build with bundle-file assertions at d643a1d. This verifies the build and native tests, not graphical browser behavior.

In review. PR #4 proposes native save/load, browser autosave, persistent seeded runs, and native/WASM replay checks. These additions remain outside main. The PR also leaves graphical browser and actual offline-install smoke checks unverified.

05 / GESTURE DETECTION

Measure temporal gestures without mixing recordings.

Problem. Overlapping frames and windows from the same recording can inflate recognition scores when they enter both training and test sets.

Architecture. Temporal windows preserve video boundaries; grouped training keeps source videos disjoint. Saved model bundles support confidence output, majority smoothing, frame-bounded event timelines, and a recorded-landmark evaluation CLI reporting window-level precision, recall, F1, confusion matrices, and rejection statistics. Supplying training-video IDs makes the evaluator reject overlapping recordings.

Verified on main · October 8, 2026. PRs #2 and #3 are merged. Python 3.11/3.12 CI passes at 2c40ce0, with leakage, schema, persistence, inference, CLI, and evaluation regression coverage plus package builds.

Measurement limits. No real held-out-corpus accuracy or robustness result is claimed. Evaluation counts overlapping windows; timing covers landmark input through prediction, excluding video decoding, pose extraction, and camera-to-event latency. Confidence rejection remains uncalibrated.
